How to use this page. The diagrams are the point. Reading that quicksort partitions around a pivot tells you almost nothing; watching the pivot land, seeing it never move again, and comparing the comparison counter against n log₂n on the same input is a different kind of knowing. Every interactive figure has a Play button and steps with the arrow keys once it has focus — and none of them autoplays, so nothing moves while you are reading.

The code. Every snippet appears in Go, Python and Java, and the switch in the bar (or g / p / j) changes all of them at once and remembers your choice. They are written to be read rather than pasted: the Go uses generics and the 1.21+ slices/maps packages, the Python is typed and targets 3.11 or later, and the Java uses records, sealed types and pattern matching where they make the shape clearer. Where a language’s standard library already solves the problem, the snippet says so instead of reimplementing it.

Complexities are worst case unless the text says otherwise, and where amortised and worst-case costs differ the page says which one it means, because that distinction is where the surprises live. Benchmark figures are orders of magnitude from a warm x86-64 machine, quoted to show a shape rather than to be a measurement of yours — the only number that matters for your code is the one you take yourself.
