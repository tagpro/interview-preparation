Most people learn algorithms as a list of names and a table of complexities, which is exactly the form in which they are useless. This page teaches them as machines: what each structure physically is in memory, what each algorithm does step by step, what it costs and when it stops being the right choice. Every diagram here runs — press play and watch the array partition, the frontier expand, the table fill. Every snippet comes in Go, Python and Java; switch with the control in the bar above.

n log nThe comparison-sort floorNot an engineering limit but a counting argument: n! orderings need at least log₂(n!) yes-or-no answers to tell apart. Every sort you will ever write is fighting for the constant, not the exponent.
~100×Contiguous vs pointer-chasedThe same n elements, the same O(n) walk. One prefetches perfectly; the other stalls on every hop. Complexity classes are silent about the difference, and your profiler is not.
One setTurns O(n²) into O(n)The single most common upgrade in real code is not a clever algorithm. It is noticing that an inner loop is asking “have I seen this before?” and giving it somewhere to remember.
