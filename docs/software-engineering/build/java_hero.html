Foundations  ·  a tutorial, beginner to advanced

Java,
then Spring.

Java is two things stacked: a language with a compiler that actually says no, and a runtime that has been tuned for twenty-five years. Spring Boot is what most of the industry runs on top of both. This page is a tutorial — every grey block is meant to be typed into a terminal and run, and the service you start building in part six is the one you take to a real database, real tests and a real container by part nine.

How to use this page

Unlike its siblings, this page has one ladder instead of three columns per topic: part one is the ground floor and part ten is the roof, so read it in order and run everything. You need a terminal, Docker (from part seven), and about ten minutes for the setup in part one. Every command block starts with $; the grey ← lines show what success looks like.
