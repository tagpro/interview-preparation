How to use this page. Each topic is self-contained: the mechanism drawn once, then the concepts that define the service, then the defaults that bite, then code you can lift. Read a section before you adopt the service and again after your first incident with it — the second reading is the one that lands.

The code. Go samples use aws-sdk-go-v2 (v1 reached end of support in July 2025); Python samples use boto3/botocore, with aioboto3 where the async version differs in an interesting way. Both are written as fragments of a real service, not as console transcripts: contexts are threaded, errors are typed, and clients are created once.

All diagrams are hand-drawn SVG. Prices are US-East-1 list, quoted to show a shape rather than to be a quote. Quotas and defaults are the ones AWS ships with — several of them are raisable, and the page says which. Version-sensitive advice reflects the mid-2026 state of the platform — last reviewed August 2026.
