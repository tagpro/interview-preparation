How to use this page. Read the L1 column of every topic first — it is a complete beginner's tour in about twenty minutes. Then come back for L2 when you are building something, and for L3 when something is slow, leaking, or failing in a way the code does not explain.

All diagrams are hand-drawn SVG. Behaviour described here is CPython — the reference implementation almost everyone runs — and where a detail is an implementation choice rather than a language rule, the page says so. Version-sensitive advice reflects the 3.13/3.14 era — last reviewed August 2026.
