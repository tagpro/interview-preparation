Python is easy to start and full of details that only surface under load: names that are not variables, defaults evaluated once, a lock that serialises your threads, and an object model that costs bytes you did not budget for. This page walks the language from first principles to production — every mechanism drawn, every topic split into what a beginner, an intermediate and an advanced engineer each need to know about it.
